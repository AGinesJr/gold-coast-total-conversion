# Canon Ledger

Status key:
- **SOURCE-ESTABLISHED** = explicitly supported by earlier source conversation or approved artifact.
- **PROVISIONAL** = working direction supported by planning, not fully reconciled.
- **PROPOSED** = new implementation or creative option awaiting approval.
- **TBD** = insufficient source evidence.
- **LOCKED** = explicitly approved immutable canon. No entry is promoted to LOCKED by an AI agent.

## Canon workflow

1. Extract claims from source conversations and authored artifacts with source link and context.
2. Tag each claim as explicit, inferred, conflicting or proposed.
3. Resolve conflicts with project owner; preserve rejected alternatives in decision history.
4. Approve a canon version; agents may not change LOCKED entries.
5. Every narrative/world artifact references canon IDs.
6. Keep an audit trail of changes and their source.
